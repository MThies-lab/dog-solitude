VIDEO ORGANIZATION INSTRUCTIONS

Folder Structure:
- videos/music-videos/        → Official music videos
- videos/live-performances/   → Live show recordings
- videos/studio-sessions/     → Studio/behind the scenes
- videos/visualizers/         → Audio visualizers

File Naming Convention:
- Use lowercase letters only
- Use hyphens (-) instead of spaces
- Keep original words - DO NOT shorten or optimize names
- Examples:
  ✓ eagles-dare-debut-full-set-april-2026.mp4
  ✓ song-name-official-music-video.mp4
  ✓ studio-session-recording-track-name.mp4
  ✗ eagles_dare.mp4 (no underscores)
  ✗ EaglesDare.mp4 (no capitals)
  ✗ video1.mp4 (not descriptive)

Video Embeds:
Most videos will be hosted on YouTube, Vimeo, or similar platforms.
Use embed codes rather than uploading large video files to the repo.

YouTube Embed Example:
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen></iframe>

Vimeo Embed Example:
<iframe src="https://player.vimeo.com/video/VIDEO_ID" width="560" height="315" frameborder="0" allowfullscreen></iframe>

For locally hosted videos (thumbnails/previews only):
- Keep file sizes reasonable (optimize for web)
- Use video posters/thumbnails linking to full videos
- Path from this file: videos/category/your-video-name.mp4

Adding Videos to Gallery Below:
1. Upload video to YouTube/Vimeo (recommended) or local folder
2. Copy the template card structure
3. Update the embed code or video path
4. Add title/description
